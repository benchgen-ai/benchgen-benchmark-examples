# Security policy

## Reporting a vulnerability

Please do **not** open a public issue for a security problem.

Email **hello@benchgen.com** with:

- what you found and where,
- steps to reproduce it,
- what you think the impact is.

We will acknowledge your report and keep you informed. We cannot promise a fixed response time yet.

## Scope

This repository contains example benchmark bundles and no production service. If you find a problem in the Benchgen platform or API itself, report it to the same address.

## If you find a secret

If you find a credential, token or private data in this repository, tell us at the address above so we can revoke it. Please do not use it.
